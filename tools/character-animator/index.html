やり直し用の設定

調整値はこのブラウザに自動保存されます。JSONへ書き出せば、ブラウザのデータを消した後でも設定だけを戻せます。画像は設定ファイルへ入りません。

軽い端末で失敗しにくい使い方

  1. 最初は360×360、3秒、12fpsで保存します。
  2. 保存できない場合は256×256か10fpsへ下げます。
  3. 透明背景が不要なら白などの背景を選ぶと、表示先による黒い縁を避けやすくなります。
  4. ホーム画面へ追加すると、1度読み込んだ後はオフラインでも起動できます。ローカルファイルとして使う方法は同じフォルダのREADMEにあります。
